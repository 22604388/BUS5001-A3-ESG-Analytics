## Q3: LLM Message Triage

Three ESG operational messages were classified using Claude claude-sonnet-4-20250514
via the Anthropic API using a revised prompt template. Results were compared
against a Facebook BART-Large-MNLI zero-shot baseline.

## Q4: NotebookLM Evaluation

NotebookLM was evaluated as an AI-powered academic assistant using an
ESG scenario. Four core features were tested and logged with observations
on accuracy, usefulness, and limitations.
